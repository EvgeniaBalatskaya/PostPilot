# Сервис управления рассылками

Проект представляет собой веб-приложение на Django для управления рассылками сообщений, администрирования клиентов и получения статистики.

---

## Описание

Цель проекта — разработать сервис, который позволяет пользователям:

- Управлять клиентами (добавлять, редактировать, удалять, просматривать).
- Создавать, редактировать и удалять сообщения.
- Организовывать рассылки и отправлять сообщения по требованию.
- Получать статистику по успешным и неуспешным попыткам рассылок.
- Ограничивать доступ пользователей в зависимости от роли (пользователь, менеджер).

Приложение подходит для «прогревающих» рассылок и удержания текущих клиентов бизнеса.

---

## Техническое задание

### Часть 1. Разработка сервиса

**1. Управление клиентами**  
Модель «Получатель рассылки»:
- `email` (строка, уникальное)
- `full_name` (строка)
- `comment` (текст)

**2. Управление сообщениями**  
Модель «Сообщение»:
- `subject` (строка)
- `body` (текст)

**3. Управление рассылками**  
Модель «Рассылка»:
- `start_time` (datetime)
- `end_time` (datetime)
- `status` (`Создана`, `Запущена`, `Завершена`)
- `message` (FK на «Сообщение»)
- `recipients` (ManyToMany с «Получатель»)

**4. Отправка сообщений по требованию**  
Реализована возможность ручной отправки через интерфейс или командную строку.

**5. Попытки рассылок**  
Модель «Попытка рассылки»:
- `attempt_time` (datetime)
- `status` (`Успешно`, `Не успешно`)
- `server_response` (текст)
- `newsletter` (FK на «Рассылка»)

**6. Главная страница**  
Отображает:
- Общее количество рассылок
- Количество активных рассылок (`Запущена`)
- Количество уникальных получателей

---

### Часть 2. Расширение функциональности

**7. Регистрация и аутентификация пользователей**  
- Подтверждение email при регистрации  
- Вход/выход из системы  
- Восстановление пароля  

**8. Статистика и отчеты**  
- Количество успешных/неуспешных попыток рассылок  
- Количество отправленных сообщений  

**9. Ограничение доступа**  
- **Пользователь**: управление своими клиентами и рассылками, просмотр статистики  
- **Менеджер**: просмотр всех клиентов и рассылок, блокировка пользователей, отключение рассылок  

**10. Кеширование**  
- Серверное и клиентское кеширование для повышения производительности  

---

### Дополнительные задания

1. **Автоматическая отправка сообщений по расписанию**  
   Через библиотеку `django-apscheduler` и скрипт для автоматической отправки сообщений.  

2. **Логирование**  
   Основные события и ошибки приложения логируются.
